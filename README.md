# react-native-i18n-kit

react-native-i18n-kit is a lightweight, dependency-free localization library for React Native built with TypeScript, Kotlin, and Swift. Supports runtime language switching, TurboModules, New Architecture, Android 10+, iOS 15+, and React Native's latest versions.

## Installation


```sh
npm install react-native-i18n-kit
```


## Usage


```js
import { multiply } from 'react-native-i18n-kit';

// ...

const result = multiply(3, 7);
```
